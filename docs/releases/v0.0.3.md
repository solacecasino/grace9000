# grace9000 0.0.3

A small patch: on a Mac, grace9000 opens the photo it's handed.

## What's new

- **Photos and edits open from Finder, the Dock and the other 9000 apps.**
  grace9000 used to start empty when macOS handed it a file (a
  double-click on a `.grace`, **Open With**, `open -a`, or leaf9000 or
  text9000 passing one on). Now it opens it, and a file sent while it's
  running opens in its window, like a drop. Windows and Linux already
  opened files named on the command line; nothing changes there.
- **`.grace` edits open in grace9000 by double-click** on a Mac, and photos
  list it under **Open With** without changing which app opens them.
- The whole 9000 series is now five apps: text9000 (writing), splice9000
(video), wave9000 (sound), grace9000 (photos) and the new
[leaf9000](https://github.com/solacecasino/leaf9000) (comics and books, the
reader Leaf renamed). Each one hands the others' files to them.

Tried on an Apple M2 with `open -a`: a JPEG opened, and a command-line
photo opened once, by absolute or relative path.

## Installing

- **macOS**: unzip, move grace9000.app to Applications, right-click → Open
  the first time. `brew install ffmpeg`.
- **Windows**: unzip anywhere, run grace9000.exe. `winget install ffmpeg`.
- **Linux**: unpack, run `./install.sh` for the app menu. Install ffmpeg
  from your distribution (7.1 or newer for phone HEIC photos).

## Compatibility

Everything from 0.0.2 works the same: `.grace` edits, settings, keys,
layouts and adapters.
