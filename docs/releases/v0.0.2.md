grace9000 comes to Windows and Linux, and opens nearly every kind of photo
file, camera raw included.

## New

- **Windows** (x64 and Arm) and **Linux** (x64 and Arm) downloads, next
  to the Mac one. Every download is built and tested by GitHub Actions: the
  tests, a real export, every photo format opened back, the built-in
  adapters opening raw and JPEG XL files, and a screenshot of the app
  running.
- **Camera raw**: Canon (CR2, CR3, CRW), Nikon (NEF, NRW), Sony (ARW),
  Fujifilm (RAF), Olympus (ORF), Panasonic (RW2), Pentax (PEF), Leica,
  Hasselblad, Phase One, Sigma, Kodak, Minolta, Samsung and DNG. Opened at
  16 bits, demosaiced, white balanced as the camera saw it, in sRGB, turned
  the way the camera was held. It's a built-in adapter, **Camera Raw**
  (rawler, from dnglab), which you can remove and add back.
- **JPEG XL**, through a second built-in adapter (jxl-oxide), with or
  without an ffmpeg that knows it, color-managed to sRGB.
- **More formats through ffmpeg**, each tested: JPEG 2000, Photoshop
  (PSD), OpenEXR, Radiance HDR, PFM, QOI, Targa, PPM/PGM/PBM/PAM, SGI, PCX,
  DPX, FITS and XWD, besides JPEG, PNG, TIFF, WebP, HEIC, AVIF, GIF and BMP.
- **Adapters can open file types** (`[[opens]]` in adapter.toml, protocol
  2): a program that turns a file into a picture. See docs/adapters.md.

## Fixed

- A HEIC stored as tiles (as phones store them) opened by an ffmpeg older
  than 7.1 used to show its first tile as the whole photo; now grace9000
  says the ffmpeg is too old.
- PAM files with 1 to 3 channels, or an unusual maximum, open.
- A photo named on the command line by a relative path opens through
  adapters too.

## Not yet

Camera raw has been tested with a DNG made for the tests, not yet with
files from real cameras: tell us how yours look. Color management beyond
sRGB, local edits, sharpening and metadata in exports are still to come.

## Installing

- **macOS**: unzip, move grace9000.app to Applications, right-click → Open
  the first time. `brew install ffmpeg`.
- **Windows**: unzip anywhere, run grace9000.exe. `winget install ffmpeg`.
- **Linux**: unpack, run `./install.sh` for the app menu. Install ffmpeg
  from your distribution (7.1 or newer for phone HEIC photos).
